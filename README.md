# tf_web

Source for [tfish.net](https://tfish.net): a single `index.html` with an animated fish bowl.

## Project bubbles

Project bubbles rise through the bowl. The bowl starts empty and the bubbles set off from the bottom one after another. Click one to pop it and open a panel with the project's title, description and image.

- Fish steer around bubbles. They don't always make it, and a bubble pops if it hits a fish or the top of the glass.
- A popped bubble comes back from the bottom on its next pass.
- Hovering or focusing a bubble stops just that one, so it's easy to click. The others keep rising, and one that rises into it pops.
- Fish near a pop dart away, then settle only halfway back, so a startle shifts their path up or down.
- Visitors with reduced motion turned on see still bubbles and no fish reactions.

To edit the projects, change the `projects` array at the top of the bubble code in the `<script>` block. Each entry has a `title`, a `description` and an `image`. The bowl has room for eight; with more, the bubbles start to overlap. The placeholder images are generated by `placeholderImage(...)`; replace them with real paths such as `'img/project-one.jpg'`.

## Fonts

Space Grotesk and JetBrains Mono are hosted in `fonts/`, so the page makes no requests to Google. `fonts/fonts.css` holds the `@font-face` rules, and only the Latin character subset is included. Both fonts are under the SIL Open Font License 1.1, and their license files (`OFL-SpaceGrotesk.txt`, `OFL-JetBrainsMono.txt`) must stay with the font files.

Open `index.html` in a browser to preview. There's no build step.
